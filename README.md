# Ichnology-Quantifying-movement
Code used in "Quantifying movement: expanding the ichnologist toolkit" paper

"Laingetal2023_Method_1_Discretization.m" takes in the curve data from adobe.

"Laingetal2023_Method_1_SI.m" processes the data and looks at the errors.

"Laingetal2023_Method_2_Segmentation.m" creates equidistant points along the curves

"Laingetal2023_Method_AllTable.m" collects data into the table

"Methods_Paper_Hyp2.ai" and "Methods_Paper.ai" contain all the images in the manscript.
